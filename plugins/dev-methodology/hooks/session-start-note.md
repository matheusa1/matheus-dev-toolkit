O plugin dev-methodology está ativo nesta sessão. É o modo padrão de
trabalho — use em toda tarefa de desenvolvimento, a menos que seja
pedido explicitamente para não usar. Ordem do fluxo: brainstorming →
writing-plans → (TDD + code-review-gate + commit-conventions por
tarefa, tarefas independentes podem rodar em paralelo) → opcionalmente
clean-architecture-scaffold para módulos novos em TypeScript. Veja a
skill using-dev-methodology para o fluxo completo.
